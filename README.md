# Fibonacci and Factorial in Python

## 📌 About the Project

This repository contains two basic Python programs: **Fibonacci Series** and **Factorial**. These programs help beginners understand fundamental programming concepts such as loops, functions, and mathematical operations in Python.

## 📂 Files Included

1. **fibonacci.py** – A Python program to generate the Fibonacci series up to a given number of terms.
2. **factorial.py** – A Python program to calculate the factorial of a given number.

## 🚀 Programs

### 1. Fibonacci Series

The Fibonacci series is a sequence in which each number is the sum of the two preceding numbers, starting from 0 and 1.

**Example:**

```text
Input: 7
Output: 0 1 1 2 3 5 8
```

### 2. Factorial

The factorial of a number is the product of all positive integers from 1 to that number. It is represented by `!`.

**Example:**

```text
Input: 5
Output: 120
```
